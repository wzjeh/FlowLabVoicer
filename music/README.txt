Drop audio files here. Supported formats: .mp3 .m4a .flac .wav .ogg .opus

The model finds songs by case-insensitive substring match on the filename.
Examples:
  一笑江湖.mp3              ← matches "一笑江湖" (default), "一笑", "江湖"
  Beethoven_5th.mp3        ← matches "beethoven", "5th"
  夜曲 - 周杰伦.m4a         ← matches "夜曲", "周杰伦"

The DEFAULT song (when no title is given) is "一笑江湖".
Drop a file named exactly "一笑江湖.mp3" (or with that substring) into this
directory to set the default.
